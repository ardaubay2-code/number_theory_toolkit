

# Number Theory Toolkit

A robust, console-based C program designed to perform various fundamental number-theoretic calculations and checks. Developed as an academic programming assignment to master control flow, loops, pointer mechanics, and input validation in C.

## Features

1. **Prime Classification**: Determines whether a given number is `PRIME`, `COMPOSITE`, or `NEITHER` (for 1).
2. **Perfect Number Check**: Evaluates if a number equals the sum of its proper divisors.
3. **Palindrome Check**: Checks if a given integer reads the same forwards and backwards.
4. **Collatz Sequence**: Generates and prints the full Collatz conjecture sequence steps for a specified number.

## How to Compile and Run

You can compile and run this program using any standard C compiler (like `gcc`):

```bash
# Compile the program
gcc number_theory_toolkit.c -o number_theory_toolkit

# Run the program
./number_theory_toolkit
